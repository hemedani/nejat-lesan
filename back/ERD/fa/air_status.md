# مدل وضعیت هوا - نمودار ERD

## نمودار موجودیت-رابطه

```
┌──────────────────────────────────┐
│         وضعیت هوا (AIR STATUS)    │
├──────────────────────────────────┤
│ فیلدهای خالص                     │
│ ┌────────────────────────────┐   │
│ │ name: رشته                 │   │
│ │ createdAt: تاریخ           │   │
│ │ updatedAt: تاریخ           │   │
│ └────────────────────────────┘   │
│                                  │
│ روابط                            │
│ ┌────────────────────────────┐   │
│ │ registrer ────► کاربر      │   │
│ └────────────────────────────┘   │
└──────────────────────────────────┘

روابط معکوس از سایر مدل‌ها:
  ◄── تصادف.air_statuses (چندتایی)
```

## فیلدهای خالص

| فیلد | نوع | توضیح |
|------|-----|-------|
| name | رشته | نام وضعیت هوا (مثلاً صاف، بارانی، مه‌آلود) |
| createdAt | تاریخ | زمان ایجاد رکورد |
| updatedAt | تاریخ | زمان آخرین بروزرسانی |

## روابط

### از وضعیت هوا به مدل‌های دیگر

| رابطه | نوع | مقصد | اختیاری | معکوس |
|-------|------|------|---------|-------|
| registrer | تکی | کاربر | بله | (ندارد) |

### روابط معکوس (از سایر مدل‌ها به وضعیت هوا)

| مدل مبدأ | رابطه | نوع | محدودیت |
|---------|-------|------|---------|
| تصادف | air_statuses | چندتایی | ۲۰ |

```json
}
```
