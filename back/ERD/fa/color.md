# مدل رنگ - نمودار ERD

## نمودار موجودیت-رابطه

```
┌──────────────────────────────────┐
│       رنگ           │
├──────────────────────────────────┤
│ فیلدهای خالص                     │
│ ┌────────────────────────────┐   │
│ │ name: رشته                 │   │
│ │ createdAt: تاریخ           │   │
│ │ updatedAt: تاریخ           │   │
│ └────────────────────────────┘   │
│                                  │
│ روابط                            │
│ ┌────────────────────────────┐   │
│ │ registrer ────► کاربر      │   │
│ └────────────────────────────┘   │
└──────────────────────────────────┘
```

## فیلدهای خالص

| فیلد | نوع | توضیح |
|------|-----|-------|
| name | رشته | نام رنگ |
| createdAt | تاریخ | زمان ایجاد رکورد |
| updatedAt | تاریخ | زمان آخرین بروزرسانی |

## روابط

### از رنگ به مدل‌های دیگر

| رابطه | نوع | مقصد | اختیاری | معکوس |
|-------|------|------|---------|-------|
| registrer | تکی | کاربر | بله | (ندارد) |

### روابط معکوس (از سایر مدل‌ها به Color)

| مدل مبدأ | رابطه | نوع | محدودیت |
|---------|-------|------|---------|
| vehicle | color | single | 1 |

```json
  "updatedAt": "2024-01-01T00:00:00.000Z"
}
```
