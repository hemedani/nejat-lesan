# Decisions — Mobile Patrol App

Recorded decisions with date, owner, and consequence. Kept in `TODO_HISTORY` so `CONTINUE.md` stays a single-page next-task prompt. Source: the Decisions section previously embedded in `CONTINUE.md`.

- [-] API base URL and environment strategy: Follow the frontend's `LESAN_URL` convention with Expo's public `EXPO_PUBLIC_LESAN_URL` at build time; the mobile client appends `/lesan`. Use `http://10.0.2.2:1404` for an Android emulator and the computer's LAN IP (not `localhost`) for a physical phone. A legacy `EXPO_PUBLIC_API_URL` fallback remains supported.
- [-] API type source: Use `back/declarations/selectInp.ts` through `@backend/*` for mobile act types. Keep the frontend-compatible runtime adapter local in `mobile/src/api/lesan-api.ts` because Metro cannot resolve runtime imports from the external frontend workspace.
- [-] Local database/storage choice: Expo SDK 57 `expo-sqlite` is selected for structured drafts, media metadata, sync queue records, and cached references. The schema/repository is implemented; migration and process-recovery tests remain pending.
- [-] Map provider and offline tile strategy: OSM-only is decided. Renderer: custom `OsmWebMap` WebView slippy-map over `tile.openstreetmap.org` with mandatory attribution — chosen after `react-native-maps` rendered blank on the tester's Android device (Google base-map dependency). Bounded patrol-area tile caching, package lifecycle, and production tile-usage terms remain open for Checkpoint 5.
- [-] Emergency online endpoint: Undecided; requires operations approval.
- [-] Emergency offline fallback: Undecided; requires operations approval.
- [-] `getSyncStatus` contract: Backend dependency remains open.
- [x] Announcement read-state: Backend `announcement_read` model is real per the 2026-08-24 backend pass (`markRead`/`getUnreadCount`/per-user `is_read`). The mobile tab uses backend read state directly (optimistic mark-read with revert); no local SQLite read tracking is kept. Push delivery (FCM/APNs) remains open on the backend.
- [x] Media upload contract: Backend pinned base64 JSON in `set.file.data {name,type,data}` for `file.uploadAccidentImages` (2026-08-24 backend pass), with `damage → facility_damage` aliasing and Patrol ownership checks. The mobile pipeline is coded but stays dormant behind `EXPO_PUBLIC_ACCIDENT_UPLOADS=on` until device-tested.
- [x] Report correction loop: For drafts with a server record, sync submits through `accident.update` keyed by `client_report_uuid`; a locally flagged «returned» report additionally calls `accident.resubmitReport(set.reportId)` after the update lands (backend contract B4). Definitive resubmit rejections clear the local flag; transport errors retry the whole record.
- [x] Severity representation: The backend has no accident severity field; the shared `type` model carries خسارتی/جرحی/فوتی. The mobile classification picker drives `data.typeId` from the loaded `type` reference list (with a local-label fallback while references are unavailable offline); the local `severity` value never enters the sync payload.
- [x] Offline map strategy: Android-only target (per product decision — no iOS build). OSM XYZ tiles mirrored to `Documents/mapcache/{z}/{x}/{y}.png` (file presence = cache; no tile index). One national Iran pack (`Documents` bbox 24.5–40°N / 43.5–64°E) with two tiers: پایه z4–10 (~4.1k tiles ≈ 60–120MB, default) and کامل z4–12 (~66k tiles ≈ 1–2GB, opt-in upgrade that keeps existing tiles). Download engine: single-flight, concurrency 4, temp-file+move atomicity, skip-existing resume, empty-tile negative cache for sea 404s, ≤3 per-tile retries, Wi-Fi-only default (overridable in-app), auto-pause offline/cellular and auto-resume on Wi-Fi for system pauses only. Map WebView HTML is hosted as a real `file://` document with `allowUniversalAccessFromFileURLs`; tiles load local-first with per-tile network fallback.
- [-] Tile source: `EXPO_PUBLIC_MAP_TILE_URL` (default `https://tile.openstreetmap.org`) — acceptable at pilot scale only; production requires a self-hosted tile server (Geofabrik `iran-latest.osm.pbf` → Docker tile service), documented as a backend follow-up. Switching sources is config-only.
- [x] Test runner: `vitest` (dev-only) runs pure domain/API unit tests via `pnpm test`; React Native/Expo modules stay out of the tested surface by keeping the domain layer free of static native imports.
- [x] SDK 57 baseline: Expo SDK `57.0.15` targets React Native `0.86`, React `19.2.3`, Android 7+ / API 36, iOS 16.4+, and Xcode 26.4+ per the versioned Expo documentation.
- [x] Current app shape: Expo Router starter scaffold with two native tabs (`Home`, `Explore`); no patrol workflow or backend integration exists yet.
